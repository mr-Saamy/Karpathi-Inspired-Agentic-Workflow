# Aider Custom Coding Conventions

- **Working Code Only**: Verify code with compiler, linter, or test commands before concluding.
- **No Fabrication**: Never invent commit hashes, paths, APIs, or test results.
- **Challenge Invalid Assumptions**: State clearly when an instruction or premise appears wrong.
- **Surgical Edits**: Touch only what the task requires. Do not refactor unrelated code.
- **Direct Communication**: Be concise. Avoid conversational filler, flattery, and emoji.
- **RTK Usage**: Prefix noisy test and build commands with `rtk` (e.g. `rtk cargo test`, `rtk pytest`).
