# Terminal / CLI Prompting Guide

## How to Get Peak Performance with Terminal AI Agents

1. **Be Direct and Specific**: State goals, constraints, and success criteria upfront.
2. **Reference Rule Files**: Ensure `CLAUDE.md` or `.aider.prompt.md` is active in the current directory.
3. **Use Prompt Templates**: Reference domain-specific prompt files in `prompts/`.
4. **Empirical Verification**: Require agents to empirically verify edits using test runners and linters prefixed with `rtk`.
