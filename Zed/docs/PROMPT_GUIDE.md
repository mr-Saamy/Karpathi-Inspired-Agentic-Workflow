# Zed Prompting Guide

## How to Get Peak Performance Out of Zed AI Assistant

1. **Be Direct and Specific**: State goals, constraints, and success criteria upfront.
2. **Use Slash Commands**: Type `/` to access custom prompt skills in `.zed/prompts/` (e.g. `/bash-scripting`, `/linux-sysadmin`).
3. **Reference Context**: Use Zed file and tab insertions (`/file`, `/tab`) to ground the assistant in exact source code.
4. **Empirical Verification**: Always ask the assistant to verify its changes with linters, tests, and compilers using `rtk`.
