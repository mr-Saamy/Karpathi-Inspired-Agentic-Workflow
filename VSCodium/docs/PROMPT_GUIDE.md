# VSCodium Prompting Guide

## How to Get Peak Performance in VSCodium / VS Code

1. **Be Direct and Specific**: State goals, constraints, and success criteria upfront.
2. **Use Specialized Modes**: In Roo-Code, switch modes according to the current task domain.
3. **Use Prompt Templates**: In Continue, attach prompt files located under `.continue/prompts/`.
4. **Empirical Verification**: Require agents to empirically verify edits using test runners and linters prefixed with `rtk`.
